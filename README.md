⚙️ Features

Configurable safe zones with coordinates and radius.

Players inside a safe zone:

Forced unarmed (no weapons).

Firing and melee attacks disabled.

Invincible while inside.

Constant on‑screen message: “You are inside a Safe Zone”.

Vehicles inside safe zones:

Max speed limited to 50 mph (≈ 22 m/s).

Leaving the zone restores normal gameplay and vehicle handling.
